# Branding Assets

## Finn Andre Logo

- Source:
  `https://finnandre.no/wp-content/uploads/2026/03/logo-customizable-1.svg`
- Retrieved with the website owner's approval on 2026-07-25.
- `finnandre-logo.svg` is the original website vector asset.
- `finnandre-logo.png` is the local Tkinter-compatible rendered asset.

The application packages these files locally and never downloads branding
assets at runtime.

## Visuino

No Visuino logo is included. Visuino is recognized through the approved
`Dedicated to Visuino` wording and the About & Dedication content.
